# プロジェクトの目的と現在地

更新日：2026-09-21

## 目的

「一歩ずつ」は、脳卒中後などの歩き方を3Dで観察し、本人が自分に近い動きを探して、リハビリ専門職との対話に使うためのWebデモです。

本人にとっての出発点は、「自分の歩きを客観的に見たい」という希望です。片麻痺では、本人が麻痺側で感じている身体の状態と、外から見える姿勢や動きが一致しないことがあります。また、「この歩き方は楽だが長時間は続かない」「去年はうまくいった方法が今年は合わない」といった変化を感じても、記憶や言葉だけでは専門職と共有しにくいことがあります。

本プロジェクトは、本人の感覚を3Dモデルの調整値や観察記録として表し、同じ歩行場面・同じ視点で見比べられるようにすることを目指します。

## 技術的な意義

- 本人にしか分からない「楽さ」「動かしにくさ」と、外から見える動きを分けて扱える
- 気になる歩行場面を止め、本人と専門職が同じ画面を見ながら話せる
- 以前と現在、疲れる前と後、杖や装具の条件などを、記憶だけに頼らず比較できる形へ発展できる
- スマートフォン動画を参照しながら、3Dモデルを本人に近づける簡易的な観察環境へ発展できる
- ブラウザー内で処理し、動画や個人情報を外部へ送らない構成にできる

経年的な変化が、感覚的、物理的、身体的、脳科学的な要因のどれによるものかを本デモが判定することはありません。変化を記録し、専門職と一緒に考えるための材料にすることが目的です。

## Ver.0.4で今回実装したこと

動かしにくい側の一歩を、次の6場面から選んで停止できるようにしました。

1. 足を着く
2. 身体を支え始める
3. 足で支える
4. 足が床から離れる
5. 足を前へ出す
6. 次の一歩を着く

あわせて、次を反映しました。

- 場面を選ぶと再生を停止し、対応するモデル周期へ移動する
- 動かしにくい側を左右で切り替えても、同じ意味の場面を表示する
- A/Bを切り替えても、選択した場面と周期を保つ
- 3Dモデルの人体としての左右が逆になっていた問題を修正する
- 杖は動かしにくい側と反対の手で持つ状態を維持する
- 杖を持つ腕の肘が人体として不自然な方向へ曲がる問題を修正する
- 場面選択、左右、杖側、肘の曲がりを対象とした最小限のテストを追加する

6場面は、観察しやすいようにモデル内へ定義した固定位置です。実際の接地時刻を動画から測定・判定したものではありません。

## 現在できること

- 代表的な6種類の歩行特徴から、近い動きを選ぶ
- つま先の上がりにくさ、脚の外回し、骨盤の持ち上げ、膝の反り返り、動かしにくい側で支える時間の短さ、上体の横傾きを調整する
- 足首の内反・外反方向の形状を表現する
- 歩幅と歩調を調整する
- 動かしにくい側、杖の有無、カメラ方向、ズーム、スロー再生、歩行周期を変更する
- 同じ歩行周期で条件Aと条件Bを見比べる
- 匿名の設定JSONを保存し、後で同じ条件を開く
- Ver.0.4では、動かしにくい側の一歩を6場面から選んで観察する

## 「左右の足を着く時間」の現在地

現在の「動かしにくい側で支える時間が短い」は、動かしにくい側の特徴を強調する既存の調整項目です。左足と右足の接地継続時間を、それぞれ独立して設定する機能ではありません。

Ver.0.4の次段階では、左足・右足それぞれについて、1歩行周期のうち接地している割合を別々に調整できるようにする予定です。ただし、表示する値はモデル内の周期割合であり、動画から測定した秒数、足底圧、荷重ではありません。

## 現在表現・実装していないもの

- スマートフォン動画の読み込みと3Dとの横並び表示
- 動画からの姿勢推定、関節角度測定、歩行イベントの自動検出
- 動画と3Dの自動同期
- 左右別の歩幅、足の上がり方、膝の曲がり、接地継続時間
- 楽さ、持続性、引っかかり、不安定さ、本人が負担を感じる部位の記録
- 以前と現在、疲労前後など、2件の記録JSONによる経時比較
- 足底圧、接触面積、身体重心、床反力、筋活動、関節負荷、杖への荷重の計算
- 医学的診断、重症度判定、正しい歩き方の判定、転倒リスク評価、個別の訓練処方

3Dモデルは、スマートフォン動画から本人の歩行を自動再現したものではありません。本人と専門職が実際の歩行や動画を見ながら、手動で本人に近づける教育・観察・対話支援用のモデルです。

## 今後の実装順序

1. **歩行場面ごとの停止**：実装済み。6場面の名称と停止姿勢を専門職に確認する
2. **左右別の調整**：歩幅、足の上がり方、膝の曲がり、支える時間を左右別にする
3. **動画と3Dの横並び表示**：端末内の動画を一時表示し、目で見て手動で合わせる
4. **身体感覚を含む観察記録**：自由記述ではなく選択式で安全に保存する
5. **2件の記録比較**：以前と現在などを同じ場面・視点で比較する
6. **専門職確認と公開判断**：誤解を招く表現や不自然な動きを優先して修正する

最初の公開判断は、段階1〜3が完成し、専門職による確認で重大な懸念がないことを目安とします。

## 開発上の方針

- 「自分の麻痺を判定する」ではなく「自分に近い動きを探す」と表現する
- 見える動きと本人の感覚を分けて扱う
- 「本人が負担を感じる部位」と、計算された物理的負荷を混同しない
- 個人のリハビリ記録、氏名、患者ID、動画、自由記述をソースコードや公開データへ入れない
- 医学的な数値に見える表示には、意味と限界を明記する
- 新しい特徴は専門職の確認を受けてから一般向けに説明する
- 既存の設定JSONとの互換性を維持する
- テストは主要動作と安全上重要な条件に絞り、過剰に増やさない

Ver.0.4の詳細な仕様と進捗は、[`openspec/changes/add-observation-comparison-v04/`](../openspec/changes/add-observation-comparison-v04/)に記録しています。

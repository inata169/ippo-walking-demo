# プロジェクトの目的と現在地

更新日：2026-09-07

## 目的

「一歩ずつ」は、脳卒中後などの歩き方を3Dで観察し、本人が自分に近い動きを探して、専門職との相談のきっかけにするためのWebデモです。

目標は診断や訓練の指示ではなく、次のような会話を助けることです。

- どの動きが自分に近く見えるか
- どこが実際の自分とは違うか
- 杖の有無や同じ歩行周期で、何が変わって見えるか
- 本人が感じていることと、外から見える動きをどう専門職へ伝えるか

## 現在の公開版

- バージョン：Ver.0.3
- 公開先：<https://inata169.github.io/ippo-walking-demo/>
- 配布条件：MIT License
- アカウント登録：不要
- 端末権限：カメラ、マイク、位置情報を使用しない
- 個人データ送信：アプリからは行わない

## Ver.0.3の基本設計

1. 代表的な6種類の動きから、本人に近いものを大まかに選びます。
2. 詳細画面で複数の特徴、足首の内外への傾き、歩幅、歩調を調整します。
3. 同じ歩行周期をA/Bで見比べます。
4. 匿名の設定JSONを保存し、後で同じ条件を開けます。

## 現在できること

- つま先が上がりにくい
- 脚を外へ回す
- 骨盤を持ち上げる
- 膝が反り返る
- 動かしにくい側で支える時間が短い
- 上体を横へ傾ける
- 足首の内反・外反方向の形状表現
- 歩幅と歩調の独立調整
- 杖、左右、カメラ、スロー再生、歩行周期の変更
- 設定の保存・再読込

## 表現していないもの

足底圧、接触面積、身体重心、床反力、筋活動、杖への荷重は計算していません。脳病変から歩き方や回復を予測せず、診断、重症度判定、転倒リスク評価、個別の訓練処方も行いません。

複数の特徴は組み合わせられますが、個人の生体力学を再現したものではありません。足首の内反・外反は見た目の形状であり、棒グラフの支え方や足底圧を変化させません。

## 開発上の方針

- 「自分の麻痺を判定する」ではなく「自分に近い動きを探す」と表現する
- 見える動きと本人の感覚を分けて扱う
- 個人のリハビリ記録、氏名、識別番号をソースコードへ入れない
- 医学的な数値に見える表示には、意味と限界を明記する
- 新しい特徴は専門職の確認を受けてから一般向けに説明する
- コードは歩行計算、支え方、3D表示、状態、保存、画面操作に分ける
- テストは主要動作と安全上重要な条件に絞り、過剰に増やさない

## 次に検討すること

1. リハビリ専門職にVer.0.3を見てもらう
2. 「動きとして不自然」「説明が誤解を招く」部分を優先して直す
3. 本人が選びやすい調整項目・順序に整理する
4. 必要性が確認できたものから、感覚メモや腕・手の動きを検討する

足幅、左右別の歩幅、感覚メモ、腕・手、坂道などは、必要性と表現方法を確認してから追加します。

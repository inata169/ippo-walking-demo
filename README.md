# 一歩ずつ — 片麻痺の歩行を見つめる3Dデモ

身体の状態や杖の有無を変え、歩き方をさまざまな方向から観察できるブラウザ向け3Dデモです。

## Ver.0.3 確認版を開く

ZIPをすべて展開して **start-review-v03.bat** をダブルクリックしてください（Windows / Python 3）。
①動きを選ぶ → ②自分に近づける → 設定JSONの保存・読込ができます。
詳細は [Ver.0.3の使い方と開発メモ](./review/v0.3/DEVELOPMENT.md) を参照してください。
従来の start-review.bat はVer.0.2用です。公開中のVer.0.1は変更していません。
複数の特徴を組み合わせる機能は、専門職確認前の説明用試作です。

## 主な操作

- 「歩く」「一歩だけ」「スロー再生」
- 動かしにくい側、脚を動かす力、こわばり、足裏の感じやすさを変更
- 杖の有無、歩く速さ、平地・ゆるい坂を変更
- カメラの向きやズームを変更
- 条件Aを保存して、変更後の条件Bと比較

## ご注意

本デモは歩行の仕組みを簡略化した教育・観察用の試作です。医学的な妥当性検証、診断、個別の歩行指導、転倒リスク評価、脳病変からの予後予測を行うものではありません。実際の練習方法や補助具の調整は、担当の医師・理学療法士などの専門職へご相談ください。

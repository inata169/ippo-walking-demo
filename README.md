# 一歩ずつ — 片麻痺の歩行を見つめる3Dデモ

身体の状態や杖の有無を変え、歩き方をさまざまな方向から観察できるブラウザ向け3Dデモです。

## Ver.0.3 公開版

公開サイト：<https://inata169.github.io/ippo-walking-demo/>

①大まかな動きを選ぶ → ②自分に近づける → 設定JSONの保存・読込ができます。
詳細は [Ver.0.3の使い方と開発メモ](./review/v0.3/DEVELOPMENT.md) を参照してください。手元では **start-review-v03.bat** をダブルクリックして確認できます（Windows / Python 3）。
複数の特徴を組み合わせる機能は、専門職確認前の説明用試作です。

## Ver.0.4 レビュー版

レビュー版：<https://inata169.github.io/ippo-walking-demo/review/v0.4/>

動かしにくい側の一歩を、次の6場面から選んで停止できるようにしました。

- 足を着く
- 身体を支え始める
- 足で支える
- 足が床から離れる
- 足を前へ出す
- 次の一歩を着く

各場面は観察しやすくするためのモデル内の固定位置で、実際の接地時刻を測定・判定するものではありません。
Ver.0.4では、正面から見た人体の左右表示と、杖を持つ側の肘の曲がり方も修正しています。
詳細は [Ver.0.4の使い方と開発メモ](./review/v0.4/DEVELOPMENT.md) を参照してください。Windowsでは **start-review-v04.bat** から起動できます。

## 技術的な意義

脳卒中後の歩行では、本人が麻痺側で感じている身体の状態と、外から見える姿勢や動きが一致しないことがあります。「一歩ずつ」は、本人の感覚を3Dモデルの調整値として表し、同じ歩行場面・同じ視点で見比べられる形にすることを目指しています。

- 本人にしか分からない「楽さ」「動かしにくさ」と、外から見える動きを分けて考えられる
- 気になる歩行場面を止め、本人とリハビリ専門職が同じ画面を見ながら話せる
- 設定JSONを残すことで、以前と現在、疲れる前と後、杖や装具の条件などを将来比較できる
- ブラウザ上で動作し、動画や個人情報を外部へ送らない観察環境へ発展できる

現在の3Dモデルは、スマートフォン動画から本人の歩行を自動測定したものではありません。本人と専門職が実際の歩行を見ながら手動で近づける、教育・観察・対話支援のための技術です。また、年ごとの変化が感覚、筋力、関節、痙縮、疲労、脳の適応などのどの要因によるものかを判定するものではありません。

## 主な操作

- 「歩く」「一歩だけ」「スロー再生」
- Ver.0.4レビュー版では、6つの歩行場面から選んで停止
- 代表的な6種類の特徴から近い動きを選択
- 特徴、足首の傾き、歩幅、歩調を細かく調整
- 動かしにくい側と杖の有無を変更
- カメラの向きやズームを変更
- 条件Aを保存して、変更後の条件Bと比較
- 匿名の設定JSONを保存・再読込

## ご注意

本デモは歩行の仕組みを簡略化した教育・観察用の試作です。医学的な妥当性検証、診断、個別の歩行指導、転倒リスク評価、脳病変からの予後予測を行うものではありません。実際の練習方法や補助具の調整は、担当の医師・理学療法士などの専門職へご相談ください。

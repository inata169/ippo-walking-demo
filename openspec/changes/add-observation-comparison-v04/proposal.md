# Change: Ver.0.4「感覚と動きを比べる」

## Why

「一歩ずつ」Ver.0.3では、代表的な歩行特徴を選び、3Dモデルを自分に近づけて観察できる。しかし、本人がスマートフォン動画で見た実際の歩行、本人にしか分からない身体感覚、以前の歩き方を同じ場で比較する手段がない。

脳卒中後の歩行では、本人が感じる麻痺側の状態と外から見える動きが一致しないことがある。また、「以前は楽だった歩き方が今は合わない」といった経年的な変化を本人が感じても、記憶だけでは専門職と共有しにくい。

Ver.0.4は、歩行を自動診断するのではなく、動画・3D表現・本人の感覚を並べ、本人とリハビリ専門職が一緒に観察するための機能を追加する。

## What Changes

1. 端末内のスマートフォン動画を、3D表示の横に一時表示する。
2. 動かしにくい側の一歩を、観察しやすい6場面で停止できるようにする。
3. 左右の歩幅、足の上げ方、膝の曲がり、支える時間を別々に調整できるようにする。
4. 楽さ、疲れ、引っかかり、不安定さ、本人が負担を感じる部位などを、選択式で記録する。
5. 以前と現在、疲労前後、杖・装具の有無など、2件の記録を同じ歩行場面で比較する。

## Scope

### In scope

- 動画はユーザーが明示的に選んだ端末内ファイルだけを扱う。
- 動画と3Dは並べて表示し、ユーザーが目で見て3D設定を調整する。
- 観察場面は臨床的な自動イベント検出ではなく、モデル内の歩行周期に定義した固定位置とする。
- 身体感覚は自由記述ではなく、選択肢として保存する。
- 比較には既存のA/B表示と同一歩行周期の考え方を再利用する。
- Ver.0.3の設定JSONは引き続き読み込めるようにする。

### Out of scope

- 動画からの姿勢推定、関節角度測定、歩行イベント自動検出
- 動画と3Dの自動同期
- 医学的診断、重症度判定、正しい歩き方の判定、訓練方法の提案
- 足底圧、床反力、筋活動、身体重心、関節負荷、杖荷重の計算
- 「負担を感じる部位」から実際の物理的負荷を推定すること
- 動画、氏名、診療記録、自由記述の保存または外部送信
- 年ごとの変化原因を、感覚的・物理的・身体的・脳科学的要因のいずれかに断定すること

## User value

- 本人が、自分の歩行を外から見た動画と3D表現で見比べられる。
- 「楽だが長くは歩けない」など、動きだけでは表せない感覚を一緒に残せる。
- 感覚と外から見える動きの違いを、専門職へ説明しやすくなる。
- 去年と今年、疲れる前と後などの変化を、記憶だけに頼らず比較できる。

## Safety and privacy

- 画面上で「観察・対話用であり、測定・診断ではない」と明示する。
- 動画はブラウザー内で一時表示し、設定JSON、記録JSON、GitHub、外部サーバーへ含めない。
- 「負担」は必ず「本人が負担を感じる部位」と表記し、計算結果に見せない。
- 記録には氏名、患者ID、診療情報、自由記述欄を設けない。
- 不正なJSONや未対応形式を読み込んだ場合、現在の状態を変更せずに拒否する。

## Delivery strategy

実装は次の順番で1項目ずつ行い、各段階で専門職が誤解しない表現かを確認する。

1. 歩行場面ごとの停止
2. 左右別の調整
3. 動画と3Dの横並び表示
4. 身体感覚を含む記録の保存
5. 2件の記録比較

最初の公開判断は1〜3が完成した時点で行う。4〜5は記録形式と説明文を専門職と確認してから一般公開する。

## Impact

- 主な変更候補: `review/v0.3/` を基にした新しいレビュー版の `index.html`, `style.css`, `app.js`, `state.js`, `patterns.js`, `gait.js`, `settings.js`
- 新規モジュール候補: `video.js`, `phases.js`, `records.js`, `comparison.js`
- 保存形式: 既存の `ippo-walking-settings` version 1は維持し、経時記録には別形式を追加する。
- 公開トップページは専門職確認が終わるまでVer.0.3のままとする。

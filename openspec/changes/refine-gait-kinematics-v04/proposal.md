# Why

v0.4の体幹が垂直に固定され、支持時間・つま先の変化が弱い。膝は0から少量の設定変更で骨盤高補正が急に有効になり、脚長制約と屈曲方向の二値切替が段階調整を妨げる。

# What Changes

- 文献を参照し、軽い体幹前傾、骨盤の動き、接地から振り出しまでの足部運動を追加する。
- 膝の符号付き目標角から骨盤高を常に求め、0〜100の調整を連続化する。
- 支持時間の短縮に反対足の接地時刻・接地時間を連動させる。飛行期を作らない。
- つま先の下向き角と床からの隙間を段階的に変え、観察値と接地時間バーを表示する。
- 観察場面を設定に応じた周期位置へ追従させる。

# Impact

対象はreview/v0.4。公開トップv0.3と保存JSONの形式は維持する。文献に基づく運動学的近似であり、筋力・床反力を解く動力学モデルではない。係数は説明用に選定し、臨床正常値・重症度には換算しない。

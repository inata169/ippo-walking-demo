# Ver.0.4レビュー版：歩行の場面を選んで観察する

## 起動

ZIPをすべて展開し、最上位の **start-review-v04.bat** をダブルクリックします。
Python 3が必要です。公開トップページはVer.0.3のままです。
その他の環境では `python start-review-v04.py` で起動します。
使用中は起動用の画面を閉じないでください。
JavaScriptはWindowsでも明示的なMIME型で配信します。外部CDNは使いません。

## 使い方

1. ①で代表的な動きと強調度、動かしにくい側を選びます。
2. 「② 自分に近づける」で選択内容を引き継ぎます。
3. 個別の動き、足首の傾き、歩幅、歩調を少しずつ調整します。
4. 「今の条件をAに保存」→調整→「Aと見比べる」で比較できます。
5. 「設定を保存」でJSONをダウンロード。「設定を開く」で復元します。
6. 「場面を選んで止める」で、動かしにくい側の一歩を6つの固定位置から観察できます。

①へ戻るだけなら詳細設定は保持します。①で特徴・強調度を選び直す時だけ確認後に初期化します。
保存するのは現在表示している条件と周期です。A/Bの両方、カメラ位置、スロー設定は保存しません。
読み込みは停止状態で行い、A/B履歴をクリアします。不正なファイルは元の設定を変えず拒否します。
保存ファイルには名前・診療記録・自由記述欄はありません。選んだファイルを端末内で読み、送信しません。
ただし個人の歩行を参考にした設定も、共有はご本人の判断で行ってください。

## 6場面の専門職確認

各ボタンは実測イベントではなく、モデル内の固定位置です。公開判断の前に次を確認してください。

1. 場面名が本人に分かりやすいか
2. 停止姿勢が場面名と大きく食い違っていないか
3. 動かしにくい側を左右で切り替えても意味が変わらないか
4. 「測定・判定ではない」という説明が十分か

## 拡張する場所

| ファイル | 責務 |
|---|---|
| patterns.js | プリセット、詳細項目定義、入力範囲、初期値 |
| gait.js | 周期と各調整値から姿勢を計算 |
| phases.js | 観察する6場面の名称とモデル周期位置 |
| support.js | 接地と足同士の相対的な支え方 |
| scene.js | 3D表示とカメラ |
| state.js | 設定変更とA/B状態 |
| settings.js | バージョン付きJSON保存・検証・復元 |
| app.js | DOM操作、再生、ファイル操作 |
| bootstrap.js | 初期読み込み失敗も画面に表示 |

詳細項目はDETAIL_FIELDSへ定義するとUIと範囲検証に反映されます。動きへの影響はgait.jsに追加してください。
保存形式を非互換変更する場合、settings.jsのversionを上げ、旧版用の明示的な移行処理を追加してください。
変更時の確認は `cd review/v0.4` → `node tests.mjs`。標準Node.jsのみで依存追加は不要です。

## モデルの限界

専門職確認前の説明用試作で、診断、重症度判定、個別の訓練処方、実際に可能な歩行の保証はしません。
特徴は同時に強調できますが、個人の生体力学を再現するものではありません。
足首の傾きは動かしにくい側の形状を変えます。接触面積・足底圧・身体重心・床反力・杖荷重は計算しません。
棒グラフは足同士の相対的な支え方で、足首の傾きから圧分布を推定しません。
脚の長さを保つため骨盤高さを補正する場合があります。複数調整値の効果が単純に加算されるとは限りません。
歩幅はモデル内の左右対称な設定です。実測値の入力や練習の推奨値ではありません。
足幅、左右別の歩幅、感覚メモ、腕・手、坂道は今回の対象外です。

2026-09-21追補：v0.4.2で、強調0の周期10%・60%付近の骨盤の急な沈み込みと、遊脚の膝・足首の急変を修正しました。基本軌道の速度・加速度を追加検証しています。重力や衝撃吸収力を解くモデルではありません。

# Ver.0.4.2レビュー版：歩行の場面と関節運動を観察する

## 起動

ZIPをすべて展開し、最上位の **start-review-v04.bat** をダブルクリックします。
Python 3が必要です。公開トップページはVer.0.3のままです。
その他の環境では `python start-review-v04.py` で起動します。
使用中は起動用の画面を閉じないでください。
JavaScriptはWindowsでも明示的なMIME型で配信します。外部CDNは使いません。

## 使い方

1. ①で代表的な動きと強調度、動かしにくい側を選びます。
2. 「② 自分に近づける」で選択内容を引き継ぎます。
3. 個別の動き、足首の傾き、歩幅、歩調を少しずつ調整します。
4. 「今の条件をAに保存」→調整→「Aと見比べる」で比較できます。
5. 「設定を保存」でJSONをダウンロード。「設定を開く」で復元します。
6. 「場面を選んで止める」で、動かしにくい側の一歩を6場面から観察できます。「足が床から離れる」などの位置は、設定した支持時間に追従します。

①へ戻るだけなら詳細設定は保持します。①で特徴・強調度を選び直す時だけ確認後に初期化します。
保存するのは現在表示している条件と周期です。A/Bの両方、カメラ位置、スロー設定は保存しません。
読み込みは停止状態で行い、A/B履歴をクリアします。不正なファイルは元の設定を変えず拒否します。
保存ファイルには名前・診療記録・自由記述欄はありません。選んだファイルを端末内で読み、送信しません。
ただし個人の歩行を参考にした設定も、共有はご本人の判断で行ってください。

## 6場面と基本歩行の専門職確認

各ボタンは実測イベントではなく、現在の設定から求めたモデル内の観察位置です。公開判断の前に次を確認してください。

1. 場面名が本人に分かりやすいか
2. 停止姿勢が場面名と大きく食い違っていないか
3. 動かしにくい側を左右で切り替えても意味が変わらないか
4. 「測定・判定ではない」という説明が十分か
5. すべての強調を0にした時、周期10%・60%付近で骨盤、股関節、膝、足首が滑らかにつながるか
6. 接地直後に膝が曲がり、その後伸びる動きと、遊脚の足首の弧が不自然でないか
7. 膝、つま先、支持時間を0・10・20・50・100と変えた時、変化が連続的で見分けられるか

## 拡張する場所

| ファイル | 責務 |
|---|---|
| patterns.js | プリセット、詳細項目定義、入力範囲、初期値 |
| gait.js | 周期と各調整値から、骨盤・股関節・膝・足首・足部の姿勢を計算 |
| phases.js | 観察する6場面の名称と、支持時間に追従するモデル周期位置 |
| support.js | 接地と足同士の相対的な支え方 |
| scene.js | 3D表示とカメラ |
| state.js | 設定変更とA/B状態 |
| settings.js | バージョン付きJSON保存・検証・復元 |
| app.js | DOM操作、再生、ファイル操作 |
| bootstrap.js | 初期読み込み失敗も画面に表示 |

詳細項目はDETAIL_FIELDSへ定義するとUIと範囲検証に反映されます。動きへの影響はgait.jsに追加してください。
保存形式を非互換変更する場合、settings.jsのversionを上げ、旧版用の明示的な移行処理を追加してください。
変更時の確認は `cd review/v0.4` → `node tests.mjs`。標準Node.jsのみで依存追加は不要です。

現在のテストは、主要な保存・A/B操作に加え、次を確認します。

- 脚長を保ち、靴が床へ貫通せず、歩行周期中に両足が同時に浮かない
- 膝、つま先、支持時間がスライダー全域で段階的に変化する
- 接地中の足が前後・左右へ滑らない
- 強調0の周期10%・60%付近で骨盤が急落しない
- 基本歩行の膝軌道に速度の折れ曲がりが生じない
- 異なる2種類の数値微分幅でも、骨盤と膝の速度・加速度が設定した上限内に収まる

## モデルの限界

専門職確認前の説明用試作で、診断、重症度判定、個別の訓練処方、実際に可能な歩行の保証はしません。
特徴は同時に強調できますが、個人の生体力学を再現するものではありません。
足首の傾きは動かしにくい側の形状を変えます。接触面積・足底圧・身体重心・床反力・杖荷重は計算しません。
棒グラフは足同士の相対的な支え方で、足首の傾きから圧分布を推定しません。
骨盤は歩行周期全体で連続した上下・左右軌道を取り、股関節・膝・足首は固定した脚長を満たすよう連動します。複数調整値の効果が単純に加算されるとは限りません。
足部は踵接地、足底接地、蹴り出し、振り出しを滑らかにつないだ幾何学的近似です。真の接触点を支点とする足部ロッカーや摩擦は計算しません。
重力、床反力、筋活動、関節モーメント、軟部組織、関節が吸収する衝撃は計算しません。滑らかな姿勢変化は、人体の衝撃吸収機構を直接再現した結果ではありません。
歩幅はモデル内の左右対称な設定です。実測値の入力や練習の推奨値ではありません。
足幅、左右別の歩幅、感覚メモ、腕・手、坂道は今回の対象外です。

## Ver.0.4.1〜0.4.2の歩行調整

v0.4.1では、軽い体幹前傾と骨盤・足部の周期運動、膝の連続調整、支持時間の左右差、つま先の見え方を修正しました。接地時間バーとモデル角度表示を追加し、場面停止を設定した支持時間へ追従させました。

v0.4.2では、強調0の周期10%・60%付近で骨盤が急に沈む問題を修正しました。骨盤を連続した周期軌道へ変更し、足部を五次補間と滑らかな床境界で扱い、遊脚の足首を単一の弧で運びます。これにより、足先が水平を通る時に生じていた膝・足首の急変も抑えました。

[文献・モデル係数・限界・確認方法](../../docs/GAIT_MODEL_V04.md)をご覧ください。OpenSpecは`openspec/changes/refine-gait-kinematics-v04/`に記録しています。

数値テストは通過しています。検証用ブラウザーではWebGLが無効なため、3Dアニメーションの最終目視確認は未完了です。

# v0.2 レビュー版の開発メモ

## 起動

リポジトリの最上位で次を実行します。

```text
python start-review.py
```

ブラウザで `review/v0.2/` が開きます。インストールは不要です。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `patterns.js` | 特徴名、選択肢、説明、調整値 |
| `gait.js` | 歩行周期から関節位置を計算 |
| `support.js` | 接地状態から左右の相対的な支え方を計算 |
| `scene.js` | Three.jsによる3D表示 |
| `state.js` | 再生状態とA/B比較の状態管理 |
| `app.js` | 画面操作と各モジュールの接続 |
| `style.css` | 画面デザイン |

## 特徴を追加する場合

1. `patterns.js` の `FEATURES` に項目を追加します。
2. `PARAMETERS` に表示用の調整値を追加します。
3. `gait.js` で歩行周期に応じた動きを計算します。
4. 必要な説明だけを `index.html` または `app.js` に追加します。
5. 既存の軽量テストに、追加機能の重要な条件だけを加えます。

特徴の組み合わせや数値の臨床的な意味づけは、専門職の確認後に追加します。

## 表示上の前提

- 6種類の代表的な特徴を単独で強調する説明用モデルです。
- 「強調する程度」は重症度や検査値ではありません。
- 支え方の棒グラフは、接地している左右の足の相対表示です。
- 足底圧、床反力、身体重心、杖への荷重は計算していません。
- 診断、個別の歩行指導、転倒リスク評価には使用できません。

## 軽量テスト

```text
cd review/v0.2
npm test
```

関節長、足の接地、支え方の合計、A/B比較の位相保持だけを確認します。
